# STUDENT_PERFORMANCE_TRACKER

## Project Title: Student performance and Attendance Data Analysis Tracker.

### Project Overview
This Data Analysis project aims to generate insight into the student performance and attendance of a particular school, by analysis the various parameters like

. Attendance rate

. Attrition count by attendance

. Attrition count by parent consent

. Percentage of home work completion

. Sum of communication rate by message type. etc in the data received.
I gather enough insight to make reasonable decision which enables me to tell a complelling stories around 
the data, from the insight gotten.

#### Data Sources
The primary source of data used here is a student performance data and it is gotten from kaggle.

#### Tools Used
. Microsoft Excel (downloadhere)(https://www.microsoftexcel.com)

1. For Data cleaning

2. For Analysis

3. For Data Visualization

. Data Visualization
Power BI for data visuals using it dashboard to visualized data and this is use to visualized the insight found in Excel.
